AI4S Cell Painting Phenotyping

Morphological phenotypic profiling of 303 chemical perturbations with JUMP-Cell Painting data (pilot source_4) — an end-to-end reproducible ML pipeline for the AI4S Open Innovation Hackathon.

Approach: Cellpose single-cell segmentation → structure-aware morphological features → cross-plate generalization validation (strict train-on-board-1 / test-on-board-2). ECFP4 fingerprints serve as SAR control only, not a phenotypic input. Well-level performance (0.768) is reported as a compound-leak signal; soft-grouped scaffold CV (AUC 0.4679) is the honest generalization estimate. Scripts 01–06 + scripts/make_demo_video_v8.py.

Reproduction

git clone https://github.com/fakenice/ai4s-cell-painting-phenotyping
pip install -r requirements.txt
# optional data download (public S3, no sign-in)
aws s3 cp --no-sign-request --recursive s3://cellpainting-gallery/cpg0000-jump-pilot/source_4/workspace/profiles/ data/profiles/

python demo.py --full     # full pipeline 01 -> 06
python scripts/make_demo_video_v8.py    # regenerate demo video v8 (1280x720, English cards)
